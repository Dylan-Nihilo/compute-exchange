## 可用素材与来源

### 阿里云

- `aliyun-logo-zh.svg`：直接提取[阿里云帮助中心](https://help.aliyun.com/zh/)页头内嵌 SVG，原始 viewBox 为 `0 0 4608 1024`，原色 `#ff6a00`。几何路径及颜色未改动。
- `alibaba-cloud-logo-en.svg`：直接提取[Alibaba Cloud 国际官网](https://www.alibabacloud.com/)页头内嵌 SVG，viewBox 为 `0 0 295.93 37.28`。仅将源 HTML 的 `viewbox` 规范为独立 SVG 所需的 `viewBox`；未改路径、颜色或比例。
- 两者均通过 XML 解析、外部脚本检查与浏览器显示检查。源 HTML、原 SVG 片段另存于证据目录。
- [官方品牌视觉规范入口](https://www.aliyun.com/about/branddesign/guidelines)。官网导航中的“品牌设计”图没有当作阿里云企业 Logo 使用。
