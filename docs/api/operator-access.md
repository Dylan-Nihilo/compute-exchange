# 运营工作台入口 — 2026-09-14

真实会话由 Go `/auth/me` 返回角色；前端会话适配器的 `grants` 为旧原型兼容字段，当前固定为空。原先逐项检查 grants 会使纯 operator 账号在后端已允许时仍被页面拒绝。

- 入口按既有 `allowedRoles` 和页面 `roles` 判定；审核、商品、订单、财务、CRM、风控、工单、Token、内容、用户及审计页面可由 operator/admin 进入。
- `/admin/access`、`/admin/settings` 保留 admin 专有页面策略；其他角色不能靠本地 grants 进入运营页面。买家KYC和供应方资质门槛保持。
- Go 继续执行实际 API 认证与角色校验；本修复只对齐前端入口，不变更账号角色、服务端RBAC或生产配置。页面可访问不代表未接入的 Token 等业务已经可用。
- 复现基线：前端 PR #37 `23087ce`、后端 PR #26 `61136ef`。同一纯运营账号对订单API得 HTTP200/code0，页面却跳至 unauthorized。
- 本修复基于 PR #37 的独立分支，验收通过后先合入 #37 的功能分支；main 合并会触发生产部署，仍需对应授权。使用隔离测试账号/数据库验证纯运营工单回复及订单允许操作；无生产发布或外部短信/支付调用。
