## 2. P0 业务正确性缺口

### 2.1 过期未支付订单不释放库存

`internal/compute/repository.go` 已定义 `IncrProductStock`，但当前没有调用方。`cmd/server/main.go` 只启动过期访问凭证吊销任务，没有扫描 `payment_expires_at` 的关单任务。

影响：买家创建订单后不付款，库存会持续被占用。应定时取消过期 `pending_payment` 订单，与库存归还放在同一事务内，且任务可重复执行。

### 2.2 退款完成不归还库存

`compute.Service.CompleteRefund` 只更新订单状态并吊销访问凭证；`payment.Service.Refund` 也只更新支付状态。两条路径都没有恢复商品余量。

退款状态、库存归还和凭证吊销应事务一致，重试不能重复加库存。

### 2.3 身份申请仍未接入后端

- 实名/企业认证表单已接入 `/user/kyc/*`，并读取持久化认证状态；试运行阶段由后端直接 mock 为 `verified`。
- 身份申请表单仍调用 `src/lib/auth/service.ts` 的 Mock 数据。
- `AccessBoundary` 暂时把 supplier/vendor/funder 的 `qualificationStatus` 视为 `approved`。后端角色 middleware 仍必须作为最终权限边界。
- 后端个人 KYC 仍未接三要素/人脸核验服务。

后续应接入真实核验服务，并把身份/角色申请、资质和 grant 接入后端契约，删除剩余 Mock 和硬编码判定。

### 2.4 运营管理仍有“假成功”接口

| 接口/能力 | 当前行为 |
|---|---|
| `ListUsers` | 恒返回空数组 |
| `FreezeUser` | 只写审计日志，不冻结用户 |
| `GetConfig` / `UpdateConfig` | 使用包内内存变量和硬编码费率，重启丢失 |
| `CreateNotice` | 只写审计日志，公告不落库 |

补齐真实行为前，这些接口应返回明确的“未实现”错误，不应返回成功。

## 3. 已有页面/接口，但尚未闭环

### 3.1 市场与下单

- 生产 `GET /api/v1/products` 返回 `code: 0`，但当前 `total: 0`，尚无可购买的真实供给数据。
- 前端没有 `/checkout` 页面，也没有从商品详情到创建订单、支付的真实闭环。
- 空心机房转询价、费率快照、幂等下单和用途声明尚未前端验收。

### 3.2 买家订单详情

- 本地工作树已实现专用 `GET /orders/:order_no`：按 JWT 当前买家归属查询，返回订单、当前商品/供给方资料、交付摘要和可用动作；前端详情页已通过 BFF 接入并完成本地 E2E，但尚未提交、发布和生产验收。
- 当前数据库没有不可变的下单商品快照和订单事件表，因此详情中的商品/供给方是当前关联资料，区块链/状态时间线仍未实现。
- 确认签收已有独立接口；详情页中的续费、退款和凭证查看操作仍需接入对应流程并完成状态机验收。

### 3.3 工作台

- 买家工作台只有概览和订单一期为真实数据。

### 3.4 发票管理（已发布生产）

- 买家侧闭环：开票信息维护（脱敏展示 + 编辑）、可开票订单选择、合并申请、历史列表、PDF 下载。

### 3.5 工单售后（本地工作树新增，未发布）

- 买家侧闭环：对本人订单发起工单（退款纠纷/资源故障/不可用/申诉/其他）、列表（状态筛选 + 工单号/标题搜索）、详情（气泡沟通记录）、追加回复、关闭。

- 运营侧通过 `GET /admin/tickets`、`POST /admin/tickets/:id/claim`、`POST /admin/tickets/:id/messages`、`POST /admin/tickets/:id/resolve`、`POST /admin/tickets/:id/close` 处理，无运营 UI。
- 未做：附件上传、SLA 超时自动升级。工单与通知中心联动已完成（详见 §3.6）。

### 3.6 消息中心（本地工作树新增，未发布）

- 买家侧闭环：通知列表（类型 Tab + 各类总数角标）、未读/已读双态卡片、标为已读（CAS 幂等）、全部已读、删除（软删）、查看详情跳转关联页面；navbar 铃铛未读角标（60s 轮询）。

## 8. 建议推进顺序

1. 过期关单与退款库存归还（P0，无外部依赖）。
2. 真实 KYC 服务商与角色申请契约接入。
3. 订单专用详情、交付凭证和履约时间线。
4. 下单页、幂等库存锁定与易宝沙箱支付。
5. 买家账单/发票/售后/消息，再推进供给方、厂商、资方和运营工作台。
6. 通知、合同、分账/对账、风控、Token/newapi 和区块链存证。
